# Power-BI-Agricultural-Dataset-Dashboard
This project displayed total farm, total yields, Average of yield by seasons, total yield by soil type and fertilizer by crop type using interactive Charts and Key performance indicator  (KPI).

# Project Highlight
- It shows that 46 farms produce 1,000 yield of crops.
- it reveals that the total area of land used for farming was 12,000.
- It shows that the crop type with the highest yield rate of 202 piece was Tomato.
- It displayed that Zaid and Kharif are the seasons with the highest portion of yields.

# Tools and Skills 
- Power query
- Power BI
- Slicer (interactive Filter)
- Visuals and Analytical story telling
- Dashboard Designs
- Key performance Indicator (KPI)

 # Key Insights
- Tomato as the highest total yield of all crops planted
- Drip which is an irrigation type produce the highest crop yield
- The total farm recorded in the data set was 46 farms
- The Average water usage is 59,000 liters
- Chart shows that 13 portion of the Farm area shows to be a clayed soil
- Kharif  as the highest pesticide usage of 36.52Kg by season

# Dashboard features
- Count of Farm_ID By Yield(tons)
- Sum of Pesticide_used(kg) By Seasons
- Count of Farm_area (acres) By Soil types
- Count of Farm_ID By Soil Type
- Total Yeild By soil types
- Average of Yield(tons) By Seasons

# Recommendation
- Farmers should improve there productivity by using in proved seeds, proper spacing and good fertilizer in other to have good increase in the next farm yield.
- Farmers should adopt proper farm management Practices, such as the use of  Organic Manure, Soil loosening and drainage system in other to improve the soil qualities as needed.
- Farmer to pay attensio9n to pest pressure and avoid excessive Pesticide Application which can in turn affect soil quality soil and water Quality.
- Since the the Total farm Area is 12k Acres then the farmer should improve on land use efficiency through proper planning farm land Area.
